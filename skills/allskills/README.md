# All Skills

This folder is a convenience mirror of the repo’s skill library. It exists so you can find a skill quickly or copy the full library into another agent workspace in one go.

## Purpose

- A single, flat index of the repo’s skill collection
- Easier discovery when you want a specific skill by name
- A convenience snapshot for copying all skills at once
- Not a separate conceptual category; it is a copy of the other skill groups

## Relationship to the rest of the library

The skills in this folder are intentionally duplicated from the more specialised subfolders:

- `experts/` holds niche or domain-specific skill groupings
- `superpowers/` holds general, reusable skills for day-to-day work
- `allskills/` is the combined lookup view for convenience

Use the other folders for structure and intent. Use this folder when you want a single place to browse or copy everything.
