# Superpowers

This folder contains broad, reusable skills that are useful across many projects, workflows, and tasks. These are the “general utility” capabilities of the library.

## Purpose

- keep universally useful skills separate from niche bundles
- make lightweight, reusable commands easy to discover
- give the library a practical set of daily-use tools for cross-project work

## Character of the skills here

Superpowers are intentionally more general than expert skills. They help in many situations without depending on a single domain or role.

Typical examples:

- planning and structure
- brainstorming and ideation
- research and synthesis
- handoff and workflow transfer
- writing and path finding
- reusable operational guidance

## Skill list

| Skill               | Purpose                                                |
| ------------------- | ------------------------------------------------------ |
| `brainstorming`     | Explore and shape ideas before implementation          |
| `caveman`           | Strip work down to the essential version               |
| `find-skills`       | Discover or locate skills to install or adapt          |
| `grill`             | Pressure-test assumptions and tease out weak spots     |
| `handoff`           | Document work and transfer context to another workflow |
| `loop`              | Repeat or iterate a process while preserving learning  |
| `pipeline`          | Sequence multiple skills in a guided flow              |
| `research`          | Research synthesis with evidence, gaps, and sources    |
| `teach`             | Teach and explain concepts clearly                     |
| `wayfinder`         | Guidance to the right next step or path                |
| `wizard`            | Guided interactive setup and operational steps         |
| `write-a-plan`      | Draft plans and task breakdowns                        |
| `write-a-reference` | Produce reference material or reusable guidance        |
| `write-a-skill`     | Create new skill files from scratch                    |

## When to use this folder

Use `superpowers/` when you want a versatile toolkit that works across:

- different projects
- different domains
- repeated day-to-day operations
- general AI-assisted planning and execution

## Compared with the other folders

- `allskills/` = full convenience mirror of everything
- `experts/` = specialized, niche, role-based skills
- `superpowers/` = general-purpose power tools for everyday use
