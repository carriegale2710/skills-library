# Experts

This folder groups specialist skill sets by niche role or domain. These are narrower, more focused collections designed for a particular kind of work rather than everyday general-purpose tasks.

## Purpose

- Keep niche skills together by expertise area
- Make it easy to load only a specialist bundle
- Group skills that work well as a role-based kit or workflow

## Character of the skills here

Experts are for skills that are highly contextual, specialized, or role-specific. Examples include:

- marketing and research
- SaaS product and deployment work
- design and UX
- developer execution and debugging
- resume and job-search support
- project-manager workflows and planning tools

## When to use this folder

Use `experts/` when you want a high-signal bundle for a specific domain or role. This is the best fit for:

- specialized workflows
- niche technical execution
- domain-oriented research and planning
- role-based toolkits

## Compared with the other folders

- `allskills/` = broad discovery and convenience mirror
- `superpowers/` = general-purpose, everyday utility skills
- `experts/` = deep, intended for a particular function or niche
