# Shared Expert Skills

This folder contains coordination skills that are common across Expert Spaces.

## 3-Expert rule

If a skill is useful to **3 or more Experts**, it belongs in `shared/`.
Shared skills are copied into each Expert Space verbatim.

## Shared skill catalog

| Skill | Purpose |
|---|---|
| `brainstorming` | Turn ideas into approved designs before implementation. |
| `grilling` | Stress-test decisions by walking a design tree in rounds. |
| `pipeline` | Chain multiple skills with stage-by-stage confirmation gates. |
| `triage` | Move issues through triage states and produce clear outcomes. |
| `to-issues` | Convert plans/specs into vertical-slice GitHub issues. |
| `to-tickets` | Break work into dependency-aware tracer-bullet tickets. |
| `writing-plans` | Produce detailed implementation plans from requirements/specs. |
| `research-to-issues` | Run research → brainstorming → issues as a gated workflow. |
| `find-skills` | Discover and install external skills for a Space. |
| `doctor` | Run a structured diagnosis workflow for ambiguous problems. |
