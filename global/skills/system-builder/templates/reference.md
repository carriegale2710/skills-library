# Reference template

On-demand detail for a skill or subagent. No frontmatter.

Save: `<skill-dir>/references/<topic>.md`. Consumer links it at the step that needs it:
`Apply [references/<topic>.md](references/<topic>.md).`

```markdown
# <Topic>

## Purpose
<What it helps; name the consumer.>

## Scope
<Covered / belongs elsewhere.>

## Rules | Patterns | Examples | Caveats
<Only sections that fit.>
```

Quality: see `references/writing-rules.md` (References).
