# Skill Library

This agent-agnostic repo to save skills for installing onto AI agent workspaces.

It provides customisable skills, references and orchestrator files to plug-and-play into your own custom workflow on top of existing AI agent platforms like Claude Code, Github Copilot or Perplexity Computer MCP (or GAIA for Perplexity Spaces - see the Github repo at carriegale2710/gaia for how it works).

## Personal Benefits

- I have free access to Pro tiers in Perplexity and Github Pilot via Education student discounts, but not for Claude Code.
- By creating a personal but agent-agnostic repo to save all my personally customised skills, I can plug and play between different agentic platforms quickly and achieve consistent outputs across different agents.
- Also good for eventually using local open source models once I can afford a better PC setup lol

## Setup

Just copy the skill files you want into your workspace.
Make sure to also copy any corresponding files if they are referenced inside other skills.

> Skills in this repo are being updated, and new skills added regularly. Check for updates for any old installations.
