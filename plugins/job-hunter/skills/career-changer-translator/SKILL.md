# Career Changer Translator

## When to Use This Skill

Use when the user is switching careers or industries, or mentions: "career change", "switching careers", "new industry", "transferable skills", "pivot".

Section choice, naming and ordering belong to `section-architect`. This skill only translates content.

## Method

1. From the master resume and the decoded job ad, list the vital criteria the user can meet with transferable skills (leadership, communication, analysis, process, client work).
2. Reword each true fact in the target field's terms (see the tables). Never invent facts, metrics or tools. Reuse `achievement-statements` for bullet structure.
3. Find the gaps and suggest honest ways to bridge them: a certification, a course, volunteer or freelance work, a side project. Offer these only as options. Never list them on the resume unless the user has done them.
4. Draft the "why I'm changing" story.

## Grouping by function

Group bullets under a transferable function only when it helps the reader. Keep each role's title, employer and dates visible:

```
PROJECT MANAGEMENT EXPERIENCE
Operations Lead | Employer A | 2021-2024
- [Translated bullet]
Coordinator | Employer B | 2018-2021
- [Translated bullet]
```

## The "why" story

Good reasons: interest grew through real exposure, the skills translate, the industry changed. Never say: burned out, hate my job, more money, easier.

```
[DISCOVERY]: "Through [experience], I found [new field]..."
[CONNECTION]: "My [old field] background gives me a different view of [new field] because..."
[ACTION]: "To prepare, I've [certifications, projects, volunteering]..."
[VISION]: "I want to bring my [transferable skill] to [target]..."
```

Use only what is true. Put it in the profile (`career-profile`), the cover letter, and interview answers (`interview-prep`).

## Output

- Transferable skills: skill, the criterion it meets, the evidence from the master resume
- Reworded bullets: original, reworded, what changed
- Gaps and honest ways to bridge them
- The "why" story
