# Note

These skills are in a hidden folder and are not part of skills-library marketplace! Used only for maintaining, updating, improving and adding new skills and functionalities.

| Skill                         | Use                                                                                                                                                            |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `productivity:write-a-skill`  | Create new skills and fix weak `description` fields, which is where routing succeeds or fails.                                                                 |
| `productivity:test-skill`     | Blind-test whether a skill triggers and behaves correctly, and check for regressions after edits.                                                              |
| `productivity:simplify`       | Trim bloated skills and references, which is also your token-cost lever.                                                                                       |
| `product-manager:reuse-first` | Check for an existing skill before adding a new one, which stops duplicates like `channel-expert` and `seo` appearing in both `founder` and `content-creator`. |
| `dev:update-docs`             | Keep README, AGENTS.md and the skills index in sync after adds, removals or renames.                                                                           |
| `dev:commit-message`          | Write consistent commits for a repo that changes in many small steps.                                                                                          |
| `dev:changelog`               | Write consistent commits for a repo that changes in many small steps.                                                                                          |

Two skills from outside the repo are worth keeping: `token-efficiency-audit` for measuring description cost, and `caveman:caveman-compress` for shrinking long SKILL.md files.
